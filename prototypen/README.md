# Prototypen

- `testdorf.html` – spielbarer Prototyp im Feldraster (fiktives Dorf Lindenhorst): Verkehrssimulation mit
  Vorfahrt, Ampeln, Kreisverkehren, Querschnitte, Zustand und Sanierung. Einfach im Browser öffnen.
- `ort-vorschau/` – erste Darstellung eines echten Ortes aus OSM-Daten.

Beide werden durch das Kachel-basierte Spiel abgelöst; Simulations- und Grafikcode lässt sich übernehmen.
